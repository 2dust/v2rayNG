# Gozar VPN | گذر

**Gozar VPN** یک برنامه اختصاصی برای مدیریت اتصال VPN در سیستم‌عامل اندروید است که با هدف ارائه اتصال پایدار، مدیریت آسان سرورها و امکانات پیشرفته شبکه توسعه یافته است.

## امکانات برنامه

- مدیریت کانفیگ‌ها و سرورها
- پشتیبانی از پروتکل‌های VLESS، VMess، Trojan، Shadowsocks، Hysteria2 و TUIC
- واردکردن کانفیگ از لینک، کلیپ‌بورد، فایل و کد QR
- مدیریت اشتراک‌ها و گروه‌های کانفیگ
- بررسی تأخیر و وضعیت سرورها
- اتصال و قطع اتصال VPN
- تنظیمات پیشرفته شبکه و مسیریابی
- مدیریت فایل‌های جغرافیایی
- نمایش گزارش‌ها و لاگ هسته اختصاصی
- پشتیبانی از زبان‌های فارسی، انگلیسی و عربی

## هسته اختصاصی

بخش «لاگ هسته اختصاصی» برای مشاهده گزارش‌های داخلی، بررسی وضعیت اتصال و عیب‌یابی در نظر گرفته شده است.

## فایل‌های منبع جغرافیایی

مسیریابی «سایت‌های ایرانی» در خروجی هسته اختصاصی به داده‌های `geosite/geoip` تکیه دارد.
