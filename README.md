# v2rayNG WL

Android-клиент V2Ray/Xray на базе [v2rayNG](https://github.com/2dust/v2rayNG) с инструментами для сетей с «белыми списками» и экспериментальной подготовкой дополнительного sing-box ядра.

Проект ориентирован на стабильность соединения, диагностику ограничений скорости и аккуратное сохранение сложных конфигураций подписок.

**Ключевые слова:** Android VPN, V2Ray, Xray, sing-box, Hysteria2, NaiveProxy, OpenConnect, AmneziaWG, белые списки, DPI, прокси, подписки.

В белых списках 2-го типа пинг проходит до любого адреса, но скорость на не разрешённых IP ограничена до десятков КБ/с — обычная проверка задержки при этом ничего не показывает.

## Поиск стабильных профилей

Главный экран → ⋮ → **«Поиск стабильных профилей (проверка БС)»**.

Проверка идёт в два этапа: сначала у всех профилей измеряется реальная задержка через ядро, затем каждый живой профиль проверяется скачиванием тестового файла через собственное временное ядро.

Рядом с пингом отображается измеренная скорость:

| | |
|---|---|
| 🟢 `3.4 MB/s` | профиль полностью пригоден |
| 🟠 `420 KB/s` | скорость понижена, но пользоваться можно |
| 🔴 `18 KB/s` | шейпинг белого списка |

- Пинг при проверке скорости не перезаписывается.
- У каждого проверенного профиля есть числовое значение скорости.
- Меню ⋮ → **«Сортировать по скорости»**.

Настройки этапов: таймаут TCP-пинга, размер тестового файла, таймаут скачивания, количество прогонов (Настройки → «Поиск по белым спискам»).

## Конвертеры подписок

В настройках каждой подписки доступны два переключателя:

- **Base64 в текст** — разворачивает base64-тело подписки в обычный список ссылок.
- **Кастомные в ссылки** — преобразует JSON-профили в обычные ссылки (`vless://`, `vmess://`, `ss://`, `trojan://`, `hysteria2://`, `tuic://` и др.), которые редактируются штатным интерфейсом.

Поддерживаются xray-outbounds, sing-box формат и полные конфиги построчно. Нераспознанные записи сохраняются как кастомные профили.

## Дополнительное ядро

GitHub Actions собирает экспериментальный `sing-box` Android core (`libbox.aar` и legacy-вариант) с поддержкой QUIC, WireGuard, NaiveProxy и OpenConnect. Это подготовительный слой для отдельного runtime-режима; текущий стабильный запуск профилей по-прежнему выполняется существующим Xray/V2Ray-контуром.

После завершения Android-адаптера sing-box через него будут доступны Hysteria2, NaiveProxy, OpenConnect и современные варианты AmneziaWG без изменения существующих Xray-профилей.

## Диагностика

- TCPing, real ping и ICMP ping доступны из меню главного экрана.
- Профили с измеренной скоростью `0 кБ/с` можно удалить отдельным действием.
- Для подписок доступны обновление через активный профиль и автоматическая обработка SHA-256 certificate pinning.

## Сборка

Сборка APK выполняется GitHub Actions. Workflow автоматически подготавливает Android SDK/NDK, собирает вспомогательные native-библиотеки и sing-box core, затем публикует APK для основных ABI.

Локальная сборка не является обязательной частью разработки проекта.
