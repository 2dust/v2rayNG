<p>Forkray is a fork of <a href="https://github.com/2dust/v2rayNG">v2rayNG</a>, the V2Ray client for Android, supporting <a href="https://github.com/XTLS/Xray-core">Xray core</a>. It follows every upstream v2rayNG release and keeps its features and settings.</p>

<h3>How it differs from v2rayNG</h3>

<ul>
<li>Built entirely from source on public CI, including the Xray core, which upstream downloads as a prebuilt library. Every release publishes the exact sources, toolchain and checksums used, so it can be rebuilt and compared byte for byte.</li>
<li>Its own application ID, so it installs alongside v2rayNG rather than replacing it.</li>
<li>No in-app update check (your F-Droid client handles updates) and no promotion link.</li>
<li>Routing databases built from freely licensed sources in <a href="https://github.com/AcideFluorhydrique/forkray-geodata">forkray-geodata</a>, instead of prebuilt downloads.</li>
</ul>

<h3>Geoip and Geosite</h3>

<ul>
<li>The bundled geoip.dat and geosite.dat come from v2fly/domain-list-community, gfwlist, china-operator-ip, DB-IP Lite and the address ranges operators publish. IP Geolocation by <a href="https://db-ip.com">DB-IP</a>.</li>
<li>They are in <code>Android/data/io.github.acidefluorhydrique.v2rayng/files/assets</code> (the path may differ on some devices).</li>
<li>The download feature fetches the larger lists from <a href="https://github.com/Loyalsoldier/v2ray-rules-dat">Loyalsoldier/v2ray-rules-dat</a> instead; it needs a working proxy.</li>
</ul>
